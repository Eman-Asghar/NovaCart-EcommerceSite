# NovaCart _ E-commerce Website

An e-commerce web application where users can search and browse products, 
add items to their wishlist or shopping cart, and complete purchases 
through a secure checkout process. Users are required to log in before 
finalizing an order, after which their order details, including product 
information, quantity, and billing details, are stored in the database.

## Tech Stack
- ASP.NET
- C#
- HTML
- CSS
- Entity Framework (database generated through code-first approach)

## Features
- Product search and browsing
- Add to wishlist / add to cart
- Login-required checkout
- Billing details and order confirmation
- Order records stored with user, product, and quantity information
